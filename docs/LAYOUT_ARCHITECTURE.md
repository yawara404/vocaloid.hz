# vocaloid.hz 画面レイアウト再考仕様書（Layout Architecture & Wireframes）

本ドキュメントは、装飾（カラー・フォント・世界観）を排し、**純粋な「画面レイアウト」「グリッド構造」「ワイヤーフレーム」「配置・レスポンシブ挙動」** に特化して `vocaloid.hz` のUI構造を根本から再考・再設計した仕様書です。

---

## 1. 全体シェルレイアウトと空間座標系（App Shell & Viewport Grid）

### 1.1 グローバルレイアウト構成図
全ページ共通の外枠（`layouts/default.vue`）における、固定要素とスクロール可能領域のZ軸・Y軸の配置関係です。

```text
+-----------------------------------------------------------------------------------+  ^
| [AppHeader]  fixed / sticky top: 0, height: 56px (h-14), z-index: 40             |  | 56px
+-----------------------------------------------------------------------------------+  v
|                                                                                   |
|  [Main Content Container]                                                         |
|  - Desktop: max-w-6xl (1152px) or max-w-7xl (1280px) 中央配置                      |
|  - Padding: px-4 sm:px-6, pt-6                                                   |
|  - スクロール可能領域（min-h-[calc(100dvh-56px-72px)])                            |
|  - 下部余白: pb-[calc(72px+env(safe-area-inset-bottom)+24px)]                     |
|                                                                                   |
+-----------------------------------------------------------------------------------+  ^
| [AppFooter]  通常フロー末尾（スクロール最下部で出現）                                |  | auto
+-----------------------------------------------------------------------------------+  v
| [PlaybackBar] fixed bottom: 0, inset-x: 0, height: 72px, z-index: 50              |  ^ 72px +
|  - pb-[env(safe-area-inset-bottom)] を内包                                       |  | SafeArea
+-----------------------------------------------------------------------------------+  v
```

### 1.2 Z-Index レイヤー構造（重なり順の厳密化）
固定要素同士の干渉を防ぐため、レイヤー階層を一元管理します。

| レベル | z-index | コンポーネント | 役割・制約 |
| :---: | :---: | :--- | :--- |
| **L0** | `0` | メインコンテンツ、背景 | 通常のドキュメントフロー |
| **L1** | `10` | Sticky 要素（目次、検索サイドバー） | スクロール追従（ヘッダー下 `top-[68px]`） |
| **L2** | `30` | [AppHeader](../components/AppHeader.vue) | 最上部固定ナビゲーション（高 56px） |
| **L3** | `40` | ヘッダードロップダウン（アカウント、テーマ） | ヘッダーから展開されるメニュー |
| **L4** | `50` | [PlaybackBar](../components/PlaybackBar.vue) | 画面最下部固定オーディオバー（高 72px + Safe Area） |
| **L5** | `60` | モバイル用ボトムシート / TOCドロワー | 下部バーの上からスライドイン |
| **L6** | `70` | グローバルモーダル（ヘルプ、確認） | 全画面オーバーレイ（backdrop-blur） |

### 2.1 記事詳細ページ（`pages/reviews/[slug].vue`）

#### 【現状のレイアウト課題】
1. **ファーストビューの動画占有**: 本文より上に巨大な 16:9 プレイヤーが固定され、文章を読むまでに大きなスクロールが必要。
2. **スクロール時の重複干渉**: スクロールするとプレイヤーが右下に浮遊し、最下部固定の `PlaybackBar` と被る。特にスマホでは画面幅の大半を覆い、文字が読めなくなる。
3. **右サイドバーの空洞化**: 記事本文が長文（3,000字以上）になるほど、右サイドバーの「楽曲データ」「マニフェスト」が早々に終わり、画面右半分が完全な空白になる。
4. **目次（TOC）の欠落**: 長文に対する道標がない。

---

##### モバイルレイアウト（< 1024px: `sm / md`）
1. **完全 1 カラム構成**: 本文の横幅を 100% 確保。
2. **動画のインライン配置 ＋ フローティング完全廃止**:

## 4. レイアウト破綻の防止ルール（CSS / 構造の制約）

1. **`min-w-0` の厳格適用（CSS Grid の横ハミ出し防止）**
   - CSS Grid 内のすべての子カラム（特に記事本文、コードブロック、長いタイトル）のラッパーに `min-w-0` を付与し、`overflow-wrap: break-word` を保証する。
2. **`sticky` 要素のコンテナクランプ**
   - 右カラムの Sticky 要素は、親要素に `items-start` を指定し、親グリッド全体の高さに引き伸ばされるのを防ぐ（引き伸ばされると Sticky が機能しなくなるため）。
3. **モバイル Safe Area の多重マージン排除**
   - 最下部の `PlaybackBar` にのみ `pb-[env(safe-area-inset-bottom)]` を持たせ、ページ本体の `main` は固定の `pb-24`（バーの高さ分）のみを確保する。
4. **YouTube IFrame の 16:9 アスペクト比維持**
   - `aspect-video w-full` を基本とし、高さ固定のピクセル指定（例: `h-[200px]`）を排除して画面幅変化による黒帯・歪みを防ぐ。
